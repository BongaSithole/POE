
# POE - Java Application

## Project Description
This project is a Java application developed as part of my
Programming Portfolio of Evidence (POE).

The application demonstrates Java programming concepts,
object-oriented programming and software development principles.

## Technologies Used
- Java
- Apache Maven
- NetBeans IDE
- Git and GitHub

## Project Structure
```text
POE/
├── .github/
│   └── workflows/
│       └── maven.yml
├── src/
├── nbactions.xml
├── pom.xml
└── README.md
```

## Requirements
- Java Development Kit (JDK)
- Apache Maven
- NetBeans IDE

## How to Run the Project
1. Clone or download the repository.
2. Open NetBeans.
3. Select File > Open Project.
4. Select the POE project folder.
5. Allow Maven to load the dependencies.
6. Clean and Build the project.
7. Run the application.
